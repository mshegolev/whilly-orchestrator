# Terminal UI themes

## Why
Existing pages force inconsistent palettes and the shared dark CSS is malformed.
Users need a consistent light/dark choice while retaining the terminal interface.

## What Changes
- Shared light, dark and system preference with local persistence and early application.
- Accessible selectors on dashboard, swarm, product cockpit and sign-in.
- Monospace typography, compact controls and line-based terminal layout preserved.

## Impact
Only UI templates, static styles/script and tests. No backend, credentials or model changes.
